# Bavinck Study Desk

성경 본문에서 시작하여 교리를 탐색하고 설교·성경공부 연구를 기록하는 한국어 웹앱입니다.

## 현재 구현

- PC 좌측 탐색, 모바일 하단 메뉴, 반응형 서가
- 다섯 본문 예시: 히브리서 12:1–2, 로마서 8:28–30, 창세기 1:26–28, 창세기 15장, 데살로니가전서 5:23–24
- 약칭·장·절 범위 검색과 한글·영문 교리 검색
- 개혁교의학 네 권의 학습용 주제 분류, 교리 상세, 초성 색인
- 성경·인물·신조 색인, 클릭 가능한 교리 지도
- 최근 연구, 북마크, 연구 노트 자동 저장
- 본문 관찰 / 교리 연구 / 적용과 질문 / 설교 구성 기록
- 판본·페이지 직접 기록, 노트 Markdown 내보내기
- JSON 전체 백업·복원 (복원은 현재 자료 교체 전 확인)

## 실행

Node.js 22 이상을 사용합니다. 외부 npm 의존성, API 키, 데이터베이스가 필요 없습니다.

```sh
npm start
```

`http://localhost:3000`에서 열립니다. `PORT` 환경 변수를 지원합니다.

```sh
npm run dev
npm run check
npm test
```

`npm run dev`는 서버 파일 변경 시 서버를 재시작합니다. 화면 코드 변경은 브라우저 새로고침으로 확인합니다. 별도의 빌드는 필요 없습니다.

## GitHub → Replit

1. GitHub에 `bavinck-study`라는 저장소를 생성합니다. 개인 연구용이므로 비공개를 권장합니다.
2. 이 폴더의 내용 전체를 저장소 루트에 업로드합니다. `package.json`, `server.mjs`, `.replit`, `src`가 루트에 있어야 합니다.
3. Replit에서 GitHub 저장소 가져오기를 통해 연결합니다.
4. 실행 명령을 `npm start`, 내부 포트를 `3000`으로 지정합니다. 저장소에 `.replit` 설정이 포함되어 있습니다.
5. 개발 후 GitHub에 커밋하여 변경을 보관합니다.

Replit 가져오기는 아직 수행하지 않았습니다. 플랫폼 UI에 따라 메뉴 이름은 다를 수 있습니다.

## 자료 신뢰도

**현재 데이터는 화면과 연구 흐름을 검증하기 위한 편집 예시입니다. 바빙크의 원문·원래 색인·실제 판본의 목차·페이지와 대조되지 않았습니다.**

- 모든 주제 연결은 `editorial-demo`, `verified: false`입니다.
- 권별 분류는 탐색 후보입니다. 정확한 장·절·페이지를 제시하지 않습니다.
- 본문 관찰은 자체 작성한 예시이며 성경 직접 인용이 아닙니다.
- 성경 전문, 바빙크 본문, AI 답변은 제공하지 않습니다.
- 인물·신조 관련성은 편집 예시입니다. 실제 언급 횟수는 생성하지 않습니다.
- 구절 범위가 겹치는 등록 예시를 반환합니다. 예를 들어 로마서 8:29 검색은 로마서 8:28–30 연구 단위를 보여줍니다.

실사용 자료를 구축할 때에는 소장 판본, 목차, 색인, 페이지 및 원문 사용 조건을 확인한 뒤 검증된 연결만 별도 추가해야 합니다.

## 저장과 개인정보

노트는 `localStorage`의 `bavinck-study-v1` 키에 저장됩니다. 서버는 노트를 받지 않습니다. 로그인 및 여러 기기 동기화는 없습니다. 브라우저 데이터 삭제 시 노트도 삭제되므로 JSON 백업을 보관하세요. 여러 탭의 동시 편집은 지원하지 않습니다. 동일 출처를 사용하는 다른 사용자·공용 기기와 저장 공간이 공유될 수 있으므로 개인 기기에서 사용하세요.

백업 손상 시 기존 자료를 덮어쓰지 않고 자동 저장을 중단합니다. 복원에 성공하면 자동 저장을 재개합니다. 입력은 HTML escape 후 표시하며 서버는 명시한 공개 파일만 제공합니다.

## 파일 구조

- `src/data.js`: 예시 자료와 출처 상태
- `src/core.js`: 검색·자료 검증·내보내기 순수 함수
- `src/app.js`: 화면·탐색·브라우저 저장
- `src/style.css`: PC/모바일 스타일
- `server.mjs`: 의존성 없는 Node 정적 서버
- `tests/core.test.js`: 본문 검색, 복원, XSS escaping, 서버 경로 제한 검증
- `.github/workflows/check.yml`: GitHub 문법 검사와 테스트
- `DEVELOPMENT.md`: 다음 개발 단계 및 출처 모델

## 아직 구현하지 않은 기능

실제 색인 데이터 수집, 원문 대조, 판본별 페이지 조회, AI 근거 검색, 원문 주해, 계정·DB·클라우드 동기화, 기존 설교 저장소 연결. 현재 앱의 결과를 검증된 바빙크 자료로 인용해서는 안 됩니다.

## 이 전달본 검증 결과

JavaScript 문법 검사와 자동 테스트 5개가 통과했습니다. 실제 브라우저 렌더링 검증은 실행 환경에 Chromium이 없고 설치 다운로드도 실패하여 완료하지 못했습니다. Replit에서 PC·모바일 화면과 다운로드·복원을 최종 확인해 주세요.
